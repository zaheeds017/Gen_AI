# Project 3 — Career Toolkit 📄💼

Turn **one** `profile.json` into three career-ready documents: a clean **resume** (Markdown + printable HTML), **LinkedIn** content (headline ideas + About section), and a **personalised interview-prep** question bank with model answers.

Covers the syllabus's **Resume**, **LinkedIn**, and **Interview Preparation** topics in a single, practical tool. **No installs — standard library only.**

---

## What it generates (into `output/`)

| File | What it is |
|---|---|
| `resume.md` | Your resume as clean Markdown (paste into any editor) |
| `resume.html` | A styled, printable resume — open in a browser, then **Print → Save as PDF** |
| `linkedin.md` | 3 headline options + a ready-to-paste **About** section |
| `interview_prep.md` | Technical Q&A **tailored to the skills in your profile**, plus behavioral STAR practice |

The interview prep is smart: it only includes topics (Python, ML, NLP, Flask, …) that appear in **your** skills list, so the practice matches your actual resume.

---

## ▶️ Run it

```bash
python career_toolkit.py
```

No installation needed. Then open `output/resume.html` in your browser.

---

## ✏️ Make it yours

Edit **`profile.json`** — it holds everything:

```json
{
  "name": "...", "title": "...", "summary": "...",
  "skills": ["Python", "Machine Learning", "..."],
  "experience": [ { "role": "...", "bullets": ["..."] } ],
  "projects":   [ { "name": "...",  "bullets": ["..."] } ],
  "education":  [ { "degree": "...", "school": "..." } ]
}
```

Re-run the script and all four documents regenerate.

## 🎯 Challenges

1. **Fill in your real profile** and generate your actual resume and LinkedIn About.
2. **Add a "cover letter" generator** — a new function that writes a short letter from `profile.json` + a company name.
3. **Grow the question bank**: add topics/questions to `QUESTION_BANK` for skills you have (e.g. SQL, Deep Learning).
4. **Tailor to a job**: add a `keywords` field to the JSON and have the resume highlight matching skills first.

> 💡 Recruiters skim for ~7 seconds. A clear, quantified, one-page resume ("cut prep time 60%", "0.82 ROC-AUC") beats a wall of adjectives.
