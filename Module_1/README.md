## ▶️ How to run any project

1. Make sure **Python 3.10 or newer** is installed. Check with:
   ```bash
   python --version
   ```
2. Open a terminal **inside that project's folder**.
3. Run the `.py` file, for example:
   ```bash
   python number_guessing_game.py
   ```

No external libraries are needed — every project uses only Python's **built-in** modules (`random`, `json`, `csv`, `os`).

## 📈 How the projects build on each other

```
Project 1  →  logic & control flow      (make decisions, repeat, handle errors)
Project 2  →  data management (CRUD)     (store, search, update, save records)
Project 3  →  data pipeline              (read → analyze → report)  ← preview of Data Science
```

Together they take you from *"writing code that decides"* to *"writing code that manages and analyzes data"* — the foundation for every module that follows.
