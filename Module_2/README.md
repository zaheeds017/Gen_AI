## ▶️ How to run any project

1. Make sure **Python 3.10 or newer** is installed (`python --version`).
2. Open a terminal **inside that project's folder**.
3. Run the `.py` file, e.g.:
   ```bash
   python ai_use_case_explorer.py
   ```

No external libraries are needed — every project uses only Python's **built-in** modules (`json`, `random`).

## 🔗 How the three projects connect

```
Project 1  →  DISCUSS   : brainstorm & prioritize AI use cases
Project 2  →  UNDERSTAND: test your grasp of AI vs ML vs DL
Project 3  →  PLAN      : walk your chosen use case through the AI lifecycle
```

Do them **1 → 2 → 3**. A great capstone for the module: take your **top use case from Project 1**, confirm you can classify its AI type with **Project 2's** knowledge, then **plan it stage-by-stage in Project 3**.
